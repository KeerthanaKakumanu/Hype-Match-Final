# 90-second demo walkthrough

1. **Role login (10 sec):** Choose Creator, Brand or Admin. Explain that role selection is instant demo login, not production authentication.
2. **Overview (10 sec):** Show the light yellow/orange/red branding and the actual workbook count: 207 candidate records, zero pre-approved eligible creators. The 1,000+ target is not presented as achieved.
3. **Creator discovery (15 sec):** Show the verified-only gate. The initial discovery list is empty until a record has a public profile URL, source URL, location evidence, language evidence, supported state/language and an explicit Verified status.
4. **Brand campaign discovery (10 sec):** Show sample campaigns and point out the visible Demo Campaign labels; these are not live brand offers.
5. **HyAI and brief builder (15 sec):** Describe the local rule-based matching/profile assistant, build a campaign brief, and track it. No paid AI API is called.
6. **Budget, chat and shortlist (10 sec):** Demonstrate the ROI calculator and message drafts; clarify that these are estimates and drafts, not guaranteed performance or live messaging.
7. **Admin (20 sec):** Review candidate evidence, import a corrected CSV/JSON record, approve only after checks, and export the data. Show `docs/data-quality-report.md` to explain the 1,000-record collection target.
