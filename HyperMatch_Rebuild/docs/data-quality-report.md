## Verification gate
A creator appears in discovery only when an admin marks the record `Verified` and the record has a public profile URL, a creator/source URL, location evidence, language evidence, a supported state (Telangana or Andhra Pradesh), and a supported language (Telugu, English or Hindi). Status alone is not enough.

## Interpretation
The workbook's 1,000-row research pipeline is a collection template, not 1,000 populated creators. Candidate rows are leads and do not imply profile identity, location, language, activity, audience size or performance has been verified. The application does not invent creator records or current audience metrics. Estimated campaign ROI is explicitly illustrative and uses user-entered assumptions.
