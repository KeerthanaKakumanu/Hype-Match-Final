# Research data notes

The included candidate database is imported from the uploaded workbook's `Creator Candidates` sheet. Candidate records retain profile/source/evidence URLs and research notes. They are not automatically approved for discovery.

## Data policy
- Discovery shows only records with an explicit `Verified` review status and the required public profile, source, location and language evidence.
- Initial eligible count is zero until a human reviewer checks and approves qualifying records.
- Blank follower, subscriber and engagement fields remain blank; no metrics were invented.
- `Research Pipeline 1000` is a blank collection template and must not be counted as creator records.
- Only use public information for creator discovery and respect each platform's terms and privacy requirements.

See `data-quality-report.md` for imported row and evidence counts.
