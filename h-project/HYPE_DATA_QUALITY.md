# HYPE creator data quality

- Records retained: 207 research candidates.
- Records with at least one profile URL: 152.
- Metrics: no follower counts or engagement rates were fabricated; cards state metrics are not independently verified.
- Status values are preserved from the source bundle. “Source-linked” means a directory/source URL exists, not identity verification or current profile validation.
- Some profile URLs were inferred from directory handles and some profiles are unavailable.
- Records with unknown niche/language/location remain searchable but show that uncertainty.
- The target is 100+ candidates, not 100+ verified profiles. Confirm each profile before outreach.
