# H-Project demo script

1. Open the live URL and show the yellow/orange/red landing experience.
2. Enter as Creator, Brand, and Admin using demo workspace buttons.
3. Create a test Creator or Brand account, sign out, and sign back in.
4. Use Discover filters and inspect a creator profile's public source/evidence links and verification status.
5. Use HyAI matching and create a structured campaign brief.
6. Save and compare creator profiles, track a demo campaign, and draft an outreach message.
7. Change assumptions in the budget/ROI estimator.
8. Enter Admin, import a CSV/JSON candidate list, review evidence, and export CSV.
9. Explain honestly that demo campaigns are illustrative, candidate records are not automatically verified, and accounts/data are browser-local prototype data.
